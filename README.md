# Restriction by days since enrolment (availability_drip)

Open an activity or section for each learner a set number of days after they enrolled in the course. Use it to release a course week by week for learners who join at different times.

- The start is the earliest active enrolment in the course, so adding a second enrolment method never resets it.
- Learners see the exact date it opens for them.
- Learners who are not enrolled never see it.

Install into `availability/condition/drip` (Moodle 4.5 to 5.3), then in an activity: Restrict access, Add restriction, Days since enrolment.
